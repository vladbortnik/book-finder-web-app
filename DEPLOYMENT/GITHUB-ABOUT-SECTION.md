## Additional Information

### Short Description (for Social Media Cards)
A direct marketplace where students can buy and sell textbooks to each other, eliminating expensive third-party resellers and ensuring fair prices for everyone.

### Key Features
- Student-to-student textbook marketplace
- User authentication and account management
- Create, read, update, and delete book posts
- Image uploads for book listings
- Department-based filtering (ANTH, BIO, CISC, ENG, MATH)
- Secure password encryption
- RESTful API design
- Containerized deployment with Docker
- Production-ready with Gunicorn

### Technology Stack
- **Backend**: Flask, Python
- **Database**: SQLAlchemy, SQLite/PostgreSQL
- **Authentication**: Flask-Login, Flask-Bcrypt
- **Forms**: Flask-WTF, WTForms
- **Frontend**: Bootstrap 4, JavaScript
- **Deployment**: Docker, Gunicorn, Nginx
- **Security**: CSRF Protection, Password Hashing

### Target Audience
College students seeking affordable textbooks
